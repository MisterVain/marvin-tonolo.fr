# marvin-tonolo.fr

Site portfolio personnel — one-page, mobile-first, présentant mes compétences de Product Owner à travers des réalisations concrètes.

**🔗 [marvin-tonolo.fr](https://marvin-tonolo.fr)** *(en ligne prochainement)*

## À propos

Portfolio présentant mes compétences en pilotage de backlog, roadmap produit et coordination d'équipes pluridisciplinaires, à travers des projets réels.

## Stack technique

- **HTML / CSS / JS vanilla** — zéro dépendance, zéro étape de build, déploiement direct
- **Polices self-hosted** (WOFF2) : Space Grotesk, Inter, IBM Plex Mono
- **Hébergement** : GitHub Pages, domaine personnalisé via OVH
- **Analytics** : GoatCounter (léger, sans cookies)
- **SEO** : données structurées Schema.org (`Person`), sitemap, meta Open Graph
